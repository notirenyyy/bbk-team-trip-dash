# Bangkok Team Trip Dashboard

This folder is ready to publish with GitHub Pages.

## Publish steps

1. Create a new GitHub repository, e.g. `bangkok-team-trip-dashboard`.
2. Upload `index.html`, `README.md`, and `.nojekyll` from this folder to the repository root.
3. In GitHub, go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Click **Save**.

GitHub will then give you a public link in this format:

`https://YOUR-USERNAME.github.io/bangkok-team-trip-dashboard/`

## Notes

- The dashboard map uses Leaflet + OpenStreetMap, so it needs internet access.
- Venue photos are loaded from external web URLs.
- Google Maps links open exact place searches/navigation in a new tab.
